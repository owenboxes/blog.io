발주 수량과 SLA 집계 범위 점검

Python 웹 실행창에서 연습할 수 있는 문제다. 아래 데이터는 연습용 가상 데이터이며, 풀이와 실행 결과는 아직 검증되지 않았다.

1. 같은 대상 목록에서 세 가지 값 계산하기

python
products = [
    {"name": "A", "stock": 2, "min_stock": 5, "price": 1000},
    {"name": "B", "stock": 5, "min_stock": 5, "price": 2000},
    {"name": "C", "stock": 0, "min_stock": 2, "price": 3000},
]

# TODO: 최소 재고보다 부족한 상품만 선택한다.
# TODO: 대상 상품의 종류 수를 구한다.
# TODO: 각 상품을 최소 재고 + 5개까지 채울 총수량을 구한다.
# TODO: 수량과 단가를 곱해 총 발주 비용을 구한다.

완료 기준:

  • 미완료 확인 항목: 현재 재고가 최소 재고와 같은 상품은 제외된다.
  • 미완료 확인 항목: 상품 종류 수와 발주 총수량을 구분해 출력한다.
  • 미완료 확인 항목: 수량과 비용을 같은 대상 목록에서 계산한다.

직접 확인할 질문: 발주 대상 목록의 len만으로 총 발주 수량을 알 수 있는가?

2. 최댓값을 찾는 범위 바꾸기

python
tickets = [
    {"id": "T01", "wait_hour": 30, "priority": "일반", "resolved": True},
    {"id": "T02", "wait_hour": 5, "priority": "긴급", "resolved": False},
    {"id": "T03", "wait_hour": 8, "priority": "일반", "resolved": False},
    {"id": "T04", "wait_hour": 9, "priority": "일반", "resolved": False},
]

# TODO: 미해결 상담만 대상으로 한다.
# TODO: 긴급은 4시간 초과, 일반은 8시간 초과인 항목을 선택한다.
# TODO: 초과 상담 ID와 건수를 출력한다.
# TODO: 초과 상담 중 가장 오래 기다린 한 건을 출력한다.
# TODO: 초과 상담이 없으면 안내 문구를 출력한다.

완료 기준:

  • 미완료 확인 항목: 해결된 상담의 대기시간이 길어도 최장 초과 상담으로 선택하지 않는다.
  • 미완료 확인 항목: 긴급 4시간·일반 8시간의 경계값을 초과와 구분한다.
  • 미완료 확인 항목: 초과 항목이 없는 데이터에서도 오류 없이 처리한다.
  • 미완료 확인 항목: 동일 최대 대기시간이 여러 건일 때 한 건 또는 전부 중 어떤 정책으로 출력할지 명시한다.

직접 확인할 질문: 건수를 세는 목록과 최댓값을 찾는 목록이 같은가?
