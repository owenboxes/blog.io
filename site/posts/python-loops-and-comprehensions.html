같은 작업을 반복하는 코드에서 데이터 추출로

문자열 출력 형식을 공부한 뒤 for·while을 작성하고, 컴프리헨션으로 변환·필터링·조건별 값을 만드는 실습을 했다. 수업 예시와 개인 작성 코드는 구분했고, 당시 실행 출력은 별도로 남기지 않았다.

컴프리헨션의 if 위치

뒤쪽 if는 항목을 남길지 결정하는 필터이고, 앞쪽 if/else는 남길 항목의 값을 고르는 표현이다. 주문별 상품을 모으는 개인 코드에서는 주문을 먼저 꺼내야 그 주문의 items를 순회할 수 있었다.

py
# 내 작성 코드를 이름만 읽기 쉽게 편집. 데이터 정의는 별도 필요하다.
paid_products = [
    item["name"]
    for order in orders
    if order["paid"] == True
    for item in order["items"]
]

이 조각만 실행하면 orders가 정의되지 않았으므로 독립 실행 예제가 아니다. 실습에는 별도 교육용 데이터를 제공해야 한다.

종료 문구와 실제 종료를 구분하기

쿠폰 번호를 최대 다섯 번 입력받는 코드와 비밀번호 코드를 작성했다. 기존 TIL의 AI 정적 점검에서는 쿠폰 코드가 정수 입력을 전제로 횟수 종료를 처리하지만 문자 입력 예외는 다루지 않는다고 구분했다.

비밀번호 코드에는 성공 시 break가 없었고, ‘10분 잠금’ 문구에 대응하는 시간 측정·차단 구현도 없었다. 안내 출력만으로 실제 잠금을 구현했다고 말할 수는 없다. 남은 실습은 성공·실패의 종료 시점과 숫자가 아닌 입력을 분리해 확인하는 것이다.

반복 코드를 검토받으며 남긴 질문

누적 while·for 연습 코드를 확인해 달라고 요청했고, 이어서 운동 챌린지와 저금통 풀이의 반복 종료 지점을 검토받으려 했다. 저금통 문제에서는 break 위치도 질문했다.

빈 좌석 문제에서는 코드를 어디서 시작해야 할지 어려워 좌석 상태를 필터링하는 방식을 물었다. 이 과정은 질문과 풀이 검토 요청의 기록이다. 최종 수정본과 실행 결과가 확인되지 않아 해결한 경험으로 정리하지는 않는다.
