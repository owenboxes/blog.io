웹 Python 실습 · AI가 제안한 연습 문제이며 작성자의 완료 기록이 아닙니다.

실습 환경

Python 실행창에서 문제를 나누어 풀고 무한 반복이 생기면 중단 버튼을 사용한다. 실제 인증·보안 시스템이나 결제 코드를 만드는 예제가 아니다.

1. 쿠폰 입력 경계값

TIL의 쿠폰 코드를 읽고 첫 시도 성공, 다섯 번째 성공, 다섯 번 실패, 문자 입력의 네 경우를 분리해 확인한다. 입력 횟수 증가 위치와 break에 도달하는 분기를 기록한다. 안내 문구만으로 실제 할인이 계산되는지 단정하지 않는다.

2. 비밀번호 종료 조건 설계

성공 시 종료와 정해진 실패 횟수에서 종료를 먼저 분리해 작성한다. ‘10분 잠금’이라는 출력과 실제 시간 기반 차단을 구분한다. 실제 계정 비밀번호는 입력하지 않는다. 완성 풀이를 본인의 수행 결과로 대신 기록하지 않는다.

3. for문을 먼저 쓰고 컴프리헨션으로 바꾸기

py
# AI가 만든 교육용 데이터. 실제 주문 데이터가 아니다.
orders = [
    {"paid": True, "items": [{"name": "커피"}, {"name": "빵"}]},
    {"paid": False, "items": [{"name": "주스"}]},
]
result = []
# TODO: 결제된 주문의 상품 이름만 result에 모으기
print(result)

먼저 일반 for문으로 완성하고, 같은 결과를 내는 컴프리헨션으로 바꾼다. order를 꺼내기 전에 order["items"]를 쓸 수 있는지 설명해 본다. TODO 상태의 코드가 정답인 것은 아니다.

오류를 보고 수정 결과를 따로 확인하기

기존 주문·상품 추출 실습을 풀 때 오류가 발생하면 오류 종류, 줄 번호, 그 줄에서 사용한 변수 이름을 먼저 기록해 본다. 코드를 수정했다면 다시 실행한 출력은 오류 기록과 나누어 남긴다.

이 항목은 복습을 위한 AI 제안이다. 오류 보고가 있었다는 사실을 실습 완료나 해결로 간주하지 않는다.
