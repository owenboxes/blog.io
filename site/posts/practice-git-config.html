실습 환경

PC의 별도 연습 저장소에서 사용하는 Git 터미널 실습이다. 블로그 Python 실행창에서 실행하지 않는다. 이 문제는 연습 제안이며 작성자의 완료 성과를 뜻하지 않는다.

1. 설정의 출처 구분

bash
git config --list --show-origin --show-scope
git rev-parse --show-toplevel

어느 설정이 system·global·local에서 왔는지, 현재 저장소의 최상위 경로가 무엇인지 구분한다. 출력에는 이메일·경로·인증 설정 등이 포함될 수 있으므로 전체를 공개 게시하지 않는다.

2. 같은 항목의 적용값 비교

현재 사용 중인 프로젝트 설정을 바꾸지 말고, 예제용 이름을 사용하는 별도 저장소에서 global 값과 local 값이 다를 때 적용 결과를 비교한다. 넓은 범위가 높은 우선순위인지 말로 설명해 본다. 기존 사용자 설정 변경은 필수가 아니다.

3. 상태와 이력 구분

작은 텍스트 변경에 대해 저장·add·commit 전후의 git status를 비교한다. 어떤 상태에서 커밋 이력이 생겼는지 적는다. SSH·PAT 인증 실습은 비밀키·토큰 없이, 별도의 환경 확인 뒤 진행한다.
