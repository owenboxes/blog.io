변수·자료형·연산자를 묶어 복습했다

Python의 변수 이름, int·float·str·bool, 비교·논리 연산과 문자열 출력 형식을 공부했다. 편집기인 VS Code와 Python 인터프리터도 구분했다.

0과 빈 값, 문자열을 다르게 보기

기존 메모에는 참·거짓 판정이 뒤바뀐 부분이 있어 AI 보충 설명으로 정정했다. 숫자 0과 빈 리스트·빈 문자열은 거짓으로 판정되지만, 문자열 "0"과 리스트 [0]은 비어 있지 않으므로 참으로 판정된다. 정정된 표를 본 사실을 직접 실행해 확인한 결과로 바꾸지는 않는다.

출력 형식은 원래 값을 바꾸지 않는다

학습 예시를 정리하면 다음 두 출력은 목적이 다르다.

py
# TIL을 바탕으로 편집한 설명 예제. 당시 내 실행 로그는 아니다.
avg = 79.753
print(f"{avg:.1f}")
print(avg)

첫 줄은 표시 자릿수를 지정하고, 둘째 줄은 원래 변수 값을 출력한다. .1f를 사용했다고 avg 자체가 새 숫자로 대입되는 것은 아니다. 숫자 반올림은 언제나 ‘5 이상 올림’이라는 한 문장으로 일반화하지 않는다.

질문과 수행 결과를 구분했다

중괄호의 의미와 분수 약분 방법도 질문했지만, 구현·채점 결과는 남아 있지 않다. 같은 날 네트워크 용어와 프로토콜을 질문한 기록은 있으나 실제 통신 실험을 한 기록은 아니다. 개인 성찰과 취업 관련 메모는 이 기술 글에서 제외했다.
