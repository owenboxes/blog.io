실습 환경

블로그 Python 실행창에서 예제를 하나씩 실행할 수 있다. 먼저 결과를 예상하고 실제 실행 결과와 비교한다. 작성자의 기존 수행 결과가 아닌 교육용 실습이다.

1. 재할당과 여러 값 할당

py
a = 1
a = 2
print(a)
a, b = 1, 2
values = 1, 2
print(a, b)
print(type(values).__name__, values)

재사용한 이름에 새 값이 대입되는 것과 예약어를 변수 이름으로 쓰는 것을 구분한다.

2. 숫자 0과 문자열 0

py
for value in [0, 1, [], [0], {}, "", "0"]:
    print(repr(value), bool(value))

리스트 안에 0이 있다는 것과 리스트가 비었다는 것이 왜 다른지 설명해 본다.

3. 표시와 원래 값

py
avg = 79.753
print(f"{avg=:.1f}")
print(avg)
name = "Alice"
print(f"|{name:<10}|")
print(f"|{name:>10}|")
print(f"|{name:^10}|")

소수 표시와 변수 값 변경을 구분하고, 폭 10보다 긴 문자열도 넣어 최소 폭의 의미를 확인한다. 예상과 달랐다면 실제 출력과 이유를 따로 적는다.
