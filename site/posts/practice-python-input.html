실습 환경

블로그 Python 실행창에서 실행할 수 있는 작은 예제로 나누었다. 각 문제는 연습 제안이며 본인의 실제 결과는 별도로 기록한다.

1. 수정·append·extend

py
items = [1, 2, 3]
items[1] = 20
items.append([4, 5])
print(items)
items.extend([6, 7])
print(items)

리스트 하나를 원소로 추가하는 것과 리스트의 원소들을 추가하는 것의 차이를 설명한다.

2. 키와 값

py
data = {"a": 1, "b": 1}
data["a"] = 2
print(data)
print(type(data.items()).__name__)
print(list(data.items()))

같을 수 있는 것은 키인지 값인지, 뷰와 리스트가 같은 형태인지 구분한다.

3. 변환 실패와 범위 초과

py
text = input("0~100 점수: ")
try:
    score = float(text)
except ValueError:
    print("숫자로 변환할 수 없습니다")
else:
    if 0 <= score <= 100:
        print("유효 범위")
    else:
        print("범위 밖")

50, 101, abc를 각각 새로 실행해 비교한다. 이 예제는 기존 검증 코드를 복원한 것이 아니라 AI가 편집한 독립 학습 예제다.
