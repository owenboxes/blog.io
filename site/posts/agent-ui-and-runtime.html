자율 연구 도구를 구성하며 만난 문제

Hermes 기반 R&D Lab을 구성하면서 PowerShell 설정 스크립트 오류와 프로필별 플러그인 불일치를 겪었다. 설정 단계를 다시 진행했고, 플러그인을 동기화한 뒤에는 UI가 표시된다고 보고했다.

다만 UI가 보인다는 것과 연구 흐름 전체가 정상 실행된다는 것은 다른 확인이었다. 탐색 결과가 있어도 기대했던 Probe·Deep Dive로 이어졌다는 근거는 아직 없었다.

오류를 구체적으로 남기기

Cron 편집 명령을 실행했을 때 unrecognized arguments 오류를 확인했다. AI는 편집 대상의 ID나 이름을 지정하는 방식을 제안했지만, 수정 명령의 실행 성공은 기록에 남아 있지 않다. 버전에 민감한 명령이므로 이 글에서 검증된 설치 가이드로 제시하지 않는다.

확인 범위를 나누어 기록했다

내가 확인·보고한 것은 설정 재시도, 프로필 동기화와 UI 표시, 명령 오류다. AI가 제시한 연구 구조나 수정 방법을 모두 적용했다고 쓰지는 않는다. 다음 확인 대상은 화면 유무가 아니라 연구 단계별 실행 로그와 실제 산출물이다.
