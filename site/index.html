01 / UNDERSTANDING

조건이 아니라 흐름으로 이해하기

반복문을 처음 배우면 “이 줄은 몇 번 실행될까?”보다 “이 문법이 맞을까?”부터 생각하게 됩니다.

하지만 코드를 이해하려면, 지금 어느 줄에 있고 다음에는 어디로 이동하는지 보는 것도 중요합니다.

다음 코드는 1부터 3까지 더합니다. 짧은 코드 안에서도 변수의 값은 여러 번 바뀝니다.

PYTHON01
total = 0
for number in range(1, 4):
    total += number
print(total)
같은 줄로 돌아오지만, 같은 상태로 돌아오는 것은 아닙니다.

02 / FOLLOW THE CHANGE

반복되는 줄, 달라지는 값

처음에는 total이 0입니다. 첫 번째 반복에서 1을 더하고, 다음에는 2를 더하고, 마지막에는 3을 더합니다. 반복이 끝나면 합계 6을 출력합니다.

START0
→
+ 11
→
+ 23
→
+ 36

아래 실습창에서 한 단계를 누르면 실행 위치를 하나씩 진행하고 멈춥니다. 강조된 줄은 방금 실행한 위치이고, 변수 패널에는 현재 멈춘 시점의 값이 표시됩니다. 함수 호출은 함수 내부로 들어가며, 반복문은 같은 줄을 다시 방문할 수 있습니다. 전체 실행에서는 줄을 강조하지 않습니다.
